# Supplementary Material

This directory contains the supplementary materials for the HIMS-CDI manuscript.

## Updated Archive
All supplementary code, data, and results have been packaged and published on Zenodo to ensure reproducibility:
- **DOI:** [10.5281/zenodo.23615735](https://doi.org/10.5281/zenodo.23615735)

Please download the `training_pipeline.zip` (v1.5.3) from Zenodo rather than relying on historical files in this directory. The Zenodo archive contains:
- The complete 10-seed training pipeline.
- The automated test suite (31 tests).
- The independent verifier.
- All canonical result CSVs (Tables 5, 7, 8).
- The environment manifest.

## Historical Files
Older files in this directory (e.g., references to v1.3.0 or v1.4.0) are preserved for historical context but should be considered superseded by the Zenodo archive above.
