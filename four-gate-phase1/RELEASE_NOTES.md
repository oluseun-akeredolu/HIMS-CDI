# HIMS-CDI four-gate Phase I — review-stage evidence release

**Manuscript:** COSE-D-26-03217 (major revision).  
**Corrected reported experiment:** `S1.zip/phase1.py` (v0.2.23), frozen outputs in `S1.zip/results/`.  
**Separate subsequent G3 candidate:** `S1.zip/g3.py` and `g3_results/` — **not** the source of the reported Phase I results.  
**Controlled CTI loopback:** `S2.zip` — not evidence of real stakeholder CTI exchange.  
**Reproduction:** `Protocol.md` and `S1.zip/verify.py`.

The prior public CDI/CCR Zenodo series and legacy v0.2.9 material are **historical, different experimental records**. The corrected four-gate study reports 240 synthetic decisions (15 eligible, 177 ineligible, 48 unresolved), 81 categorical gate combinations, 59,049 nested combinations, and bounded CTI loopback fixtures. No clinical or operational validation is claimed. Reviewer 1's additional independent SLR request has not been fulfilled by an independently screened SLR.

S3 review tables, selected external PDFs, original H1 coding files, and researcher approval records are **not automatically uploaded** by this utility; these require a separate rights and privacy review. No prior DOI or public repository file is overwritten.

This package contains a technical upload workflow, not third-party independent certification, legal compliance confirmation, or co-author consent.
